# Вспомогательные скрипты

## Скрипт write_bin_to_sqlite.py

Скрипт записывает пользовательские данные из файла **keyfile.bin** старого формата в файл **keyfile.sqlite**.

1. Положите файл **keyfile.bin** в папку со скриптом **write_bin_to_sqlite.py**.

2. В командной строке запустите скрипт:

   ```bash
   python write_bin_to_sqlite.py
   ```
